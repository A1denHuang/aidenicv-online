# AidenICV

AidenICV 是一个面向数字 IC 验证学习者的中文互动题库与知识库，覆盖 SystemVerilog、UVM、AMBA / AXI 协议和校招面试准备。

## 功能

- SV、UVM、AXI 开放问答训练
- 掌握、模糊、不会三档自评与薄弱题复习
- 中文全文搜索与分类浏览
- 119 篇学习笔记、面经、笔试和场景资料
- 学习进度保存在当前浏览器，无需登录

## 本地开发

```bash
pnpm install
pnpm dev
```

运行测试和生产构建：

```bash
pnpm test
pnpm build
```
