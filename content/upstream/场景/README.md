# 🧩 场景设计题

> 验证岗面试的隐藏重点：给一个模块/故障，现场讲清"怎么验证、怎么排查"。靠验证思维，不靠背。

## 三类题型

| 类型 | 题数 | 代表 |
|------|:---:|------|
| 📐 模块验证方案 | 7 | feature 拆分、寄存器验证计划、AXI 死锁验证、IP 乱序 OTSD |
| 🔍 故障排查 | 7 | rdata 晚一拍、scoreboard 不匹配、死循环/挂死 debug |
| ⚖️ 设计权衡 | 3 | UT vs SOC、EDA 局限、IP vs SOC |

## 答题框架

```text
拆 feature → 分测试点 → 定验证策略（定向/随机 + checker/覆盖率）→ 排障（现象→缩小范围→定位→修复→回归留档）
```
