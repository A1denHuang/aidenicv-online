## 使用

1. 先**手写**再对答案（面试白板 = 无编译器，平时练到"手写能过"）。
2. 写完代码 + testbench 可提交到本目录或 [systemverilog-learning](https://github.com/qingxuanxx/systemverilog-learning) 对应章节。
3. 状态自行标注：未做 / 已做 / 已跑通 / 面试被问。
