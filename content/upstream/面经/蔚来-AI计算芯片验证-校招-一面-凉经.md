# 蔚来 AI计算芯片验证 一面凉经

> 来源：小红书汇总帖 | 时长 36 分钟，面试官专业友好。

## 项目部分

- 针对项目提问，面试官结合过往项目经验指出验证环境潜在缺陷

## 八股考点

- AXI 是否支持写乱序/写交织
- AXI slave vip 的 memory 模型搭建方式与所用数组
- uvm phase 机制完整分类、可放置延时的 phase
- run phase 和 main phase 能否同时使用
- objection 机制
- 验证环境组件与构建顺序
- interface 传递至组件的方式、传递层级、不能传递真实物理接口的原因
- virtual sequence/sequencer 原理与使用意义
