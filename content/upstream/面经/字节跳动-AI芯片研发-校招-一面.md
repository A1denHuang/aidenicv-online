# 字节跳动 AI芯片研发 一面面经（60 分钟）

> 来源：小红书汇总帖 | 整体面试强度较高、细节提问多，面试官愿意解释知识点。

## AXI 总线高频问题

- 三个写通道、两个读通道的设计原因
- outstanding 定义与验证方法
- 反压出现场景
- 上游 64B、下游 32B 场景下传输正确性验证
- burst length=5 且首笔不对齐时下游传输笔数
- 对端未初始化带来的问题
- 乱序传输识别方法
- wstrb 信号作用

## PCIe 考点

- 协议分层（事务层、链路层、物理层），每层验证思路
- 事务层四种请求类型
- non-post 与 post 区别
- 链路层重传机制
- 物理层 PCS、PMA、SerDes 相关
- Gen4 的 128b/130b 编码
- 链路训练 LTSSM 各个状态

## RISC 处理器验证考点

- 指令正确性验证方案
- C-model 建模方法
- 处理器性能评估方式

## 手撕 SystemVerilog

- 约束要求数组元素 100~1000，100-500 权重高于 501-1000
- 覆盖 array[0] 的 200、300、500、800

## UVM 机制

- sequence 和 monitor 的数据传输方式
- factory 机制

## SystemVerilog 与 OOP

- 父类子类句柄关系
- cast 使用场景
- virtual 实现多态
- config_db 中 virtual 的用途

## 反问环节

- 字节芯片部门规划、面试流程、应届生培养路线
- 业务以自研自用为主，新人从小模块 IP 逐步过渡到 SoC 项目
