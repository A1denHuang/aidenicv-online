# 海光 数字IC验证 校招面经

> 来源：小红书汇总帖 | 面试流程：项目面、UVM基础面、主管面，每轮约 40 分钟。

## 项目面

- 遇到仿真死循环卡住时快速 debug 的方法
- UVM 环境实现 C 编译的原理
- 项目部分提问因人而异

## UVM 基础面

- m_sequencer 和 p_sequencer 的区别及转化方式
- deposit 和 force 的区别
- 寄存器模型 auto predict
- 寄存器模型后门访问实现
- 通过 uvm factory 机制实现 enable 信号开关

## 面试小提示

- 海光是 CPU 相关企业：项目环节常提问**中断相关测试、异常测试**；项目涉及 C code 会深入考察
- UVM 基础面重点考察**寄存器模型相关全部知识点**，需重点准备
