# IC 验证周报

每周筛选数字 IC 验证领域值得关注的一手信息，关注标准、工具、开源项目、工程实践、行业动态与优质技术资料。

> [!info] 发布说明
> 周报计划每周发布一期。内容优先引用项目官网、标准组织、论文原文、厂商技术资料与开发者公告，并附原始链接和发布日期；未经核实的转载与传闻不作为主要信源。

> [!tip] 先读这一篇
> [[IC验证周报/第37-43周知识合集|第 37–43 周知识合集]] 把前七期中可复用的验证知识按主题重新整理，含最小用例和检查清单。新读者从这里开始即可，不必逐期翻阅。

## 每期内容（自第 44 周起）

从第 44 周开始，周报从“新闻汇总”改为“知识周报”：上游动态只作为选题来源，每期的主体是一个讲透的技术点。

| 栏目 | 篇幅 | 内容 |
| --- | --- | --- |
| **本期专题** | 约 50% | 一个技术点讲透：原理 → 最小可运行例子（RTL / testbench / SVA + 预期结果）→ 常见坑 → 检查清单 |
| **概念拆解** | 约 15% | 一个核心概念的工作机制，例如 RAL predictor 模式、objection 与 drain time、clocking block 时序 |
| **找 Bug** | 约 10% | 一段有问题的 SV / UVM / cocotb 代码，先给读者找，答案折叠在后面 |
| **业界速读** | 约 15% | 3–5 条一手动态，每条不超过两句，并回答“这对我写 testbench 有什么影响” |
| **思考题** | 约 5% | 一道开放问题，下期公布参考答案 |
| **知识地图** | 一行 | 标注本期覆盖的能力维度 |

**知识地图维度**：激励生成 · 检查（scoreboard / SVA）· 覆盖率 · 形式验证 · CDC / RDC · 低功耗 · 回归与基础设施 · 调试 · 需求追溯 · 工具与语言语义

## 阅读约定

- 每期文章使用 `YYYY年第WW周` 命名，并在开头标注信息覆盖日期。
- 业界速读的每条动态都附原始链接和日期，并区分事实、官方说法和作者判断；专题中的示例代码在开源仿真器上实际运行过。
- 某一周没有值得收录的动态时，业界速读可以留空，但专题照常发布。
- 每积累约 6–8 期，按主题整理一次知识合集。
