# 示例项目：可复用验证环境

## 项目目标

为一个简单总线从设备建立可复用、可回归的验证环境，并用文档记录关键设计决策。

## 结构

| 层次         | 组件             | 职责               |
| ------------ | ---------------- | ------------------ |
| stimulus     | sequence         | 产生事务           |
| active agent | driver / monitor | 驱动与采样接口     |
| checking     | scoreboard       | 比对期望与实际结果 |
| coverage     | subscriber       | 收集功能覆盖率     |

> [!success] 完成标准
> 测试可以一条命令运行；失败时日志能够定位到事务；覆盖率缺口能回到验证计划。
